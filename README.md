# Cari Crochet — "Arte en cada puntada" 🧶🌸

Sitio web publicitario, artesanal y profesional desarrollado para el emprendimiento de crochet **Cari Crochet**, perteneciente a **Carito Ayala** ([@cariicrochet_13](https://instagram.com/cariicrochet_13)).

---

## ✨ Características Principales

- **Identidad de Marca Artesanal:** Paleta de colores cálida (crema, rosa suave, verde salvia, café tierra) y tipografía elegante (`Playfair Display`, `Fraunces`, `Plus Jakarta Sans`).
- **Fotografías Reales:** Integración de imágenes en alta resolución del catálogo de creaciones (amigurumis, carteras en trapillo, recuerdos de graduación, llaveros y accesorios).
- **Galería Interactiva con Lightbox:** Visor a pantalla completa con navegación por teclado (flechas / ESC) y soporte para gestos táctiles (*swipe*) en dispositivos móviles.
- **Asistente de Pedidos a WhatsApp:** Modal interactivo que pre-configura mensajes estructurados según la pieza seleccionada por el cliente.
- **100% Responsivo:** Adaptado para teléfonos móviles (*mobile-first*), tablets, laptops y pantallas de escritorio.
- **Optimizado y Ligero:** Sin dependencias pesadas; construido con HTML5 semántico, CSS3 modular y JavaScript Vanilla.

## 🚀 Instalación y Visualización Local

1. Clona el repositorio:
   ```bash
   git clone https://github.com/HeriJosue123/cariicrochet_13.git
   ```
2. Abre la carpeta del proyecto:
   ```bash
   cd cariicrochet_13
   ```
3. Inicia un servidor local o abre `index.html` en tu navegador:
   ```bash
   # Con Python:
   python -m http.server 8080
   ```
   Luego visita `http://localhost:8080`.
